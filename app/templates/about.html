About StockInsight

StockInsight is an advanced financial web platform designed for investors, market analysts, and enthusiasts to explore real-time stock market dynamics and make data-driven forecasts.

Key System Features

Real-Time Predictions

Forecast future stock trends using Linear Regression and Scikit-Learn models.

Interactive Charts

Dynamic Plotly charts for deep historical price visualization and trend analysis.

Live Yahoo Finance API

Seamless integration fetching accurate, live historical stock market datasets.

Modern Glass UI

Responsive cyberpunk glassmorphism interface built with Django and Python.
